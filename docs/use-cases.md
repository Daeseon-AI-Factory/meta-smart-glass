# Use Cases

본인이 만들고 싶은 것들 + 단계별 우선순위.

---

## Phase 1: Validation (Month 1-2) — 본인 자신 사용

검증 목표: "본인이 매일 쓸 만한가?"

### Core (필수)
- [ ] **실시간 영어 자막** (Live Captions)
  - 마이크 → STT → 디스플레이
  - 한국어/영어 양방향
  - latency <500ms 목표

- [ ] **영어 답변 제안** (Conversation Coach)
  - 회의/대화 중 본인 다음 답변 2-3개 제안
  - LLM (gpt-4o-mini) 호출
  - 본인 워홀 컨텍스트 반영 프롬프트

### Should Have
- [ ] **본인 목소리 인지** (Speaker Diarization)
  - "본인 vs 타인" 구분
  - 본인이 말한 거 skip
  - 30초 voice enrollment

- [ ] **메뉴/표지판 OCR**
  - Apple Vision Framework
  - 추출 텍스트 → 번역 (한국어)

---

## Phase 2: Expansion (Month 3-6) — 본인 사용 + 친구 테스터

### Core
- [ ] **물체 영어 라벨링**
  - YOLO 또는 Apple Vision
  - 실시간 (15+ FPS)
  - 영어 단어 학습 보조

- [ ] **회의 요약**
  - 회의 끝나면 자동 요약
  - 결정사항/액션아이템/follow-up 분류
  - 본인 노션/캘린더 연동

### Nice to Have
- [ ] **표정 분석**
  - GPT-4o Vision
  - 상대방 감정 추측 (조심스럽게)
  - 본인 self-feedback 위주

- [ ] **컨텍스트 알림**
  - 캘린더 다음 미팅 정보
  - 본인 todo 시야 표시

## Phase 3: Commercial Pivot (Year 2+) — B2B

### 한국 시장 타겟
- [ ] **외국인 노동자 산업 트레이닝**
  - 한국 제조업 (삼성/LG/SK 자회사 등)
  - 외국인 노동자 모국어 (베트남/태국/네팔/우즈벡)
  - 작업 절차 안내 + 안전 경고
  - 한국어 매니저 ↔ 외국인 작업자 실시간 번역

### B2B 기능
- [ ] **관리자 대시보드** (웹)
  - 작업자별 진행 상황
  - 트레이닝 완료 인증
  - 산재 예방 메트릭

- [ ] **다국어 지원**
  - 한국어/영어 외 동남아 언어
  - 음성 + 텍스트 양방향

## Architectural 한계 (못 만들 것)
- ❌ **운동 자세 교정**: 글래스 카메라는 본인을 안 봄. 거울/외부 카메라 별도 셋업 필요.
- ❌ **Meta AI 통합**: "Hey Meta" 외부 개발자 사용 불가 (Meta 정책)
- ❌ **글래스 자체 GPS**: Display 자체 GPS X. 폰 GPS 경유

---

## 검증 지표
"본인 매일 쓸 만한가" 평가:
- 일 사용 횟수: 5회+ → 가치 있음
- 일 사용 횟수: 1회 미만 → 재검토
- 끄고 싶은 순간 vs 켜고 싶은 순간 비율
- 친구들 반응 (사회적 수용성)
